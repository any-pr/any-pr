# 論自動合併拉取請求之律

**庫：** any-pr ｜ **行法之器：** `.github/workflows/auto-merge.yml`

> 此為節譯，正本見 [`CONTRIBUTING.md`](./CONTRIBUTING.md)。

## 第一條 — 通則
凡投牒求合於此庫者，其可合之條件，悉依此律。自始至終，不假人手。

## 第二條 — 自動合併
凡非草稿之請，合於第三條者，即徑以壓縮之提交合之，並刪其源枝。草稿未撤，則不合。

## 第三條 — 當閉之事
凡有下列情事者，閉而不合：改 `.github/` 者；改授權文書或 README 者；納禁物者；設符號連結或子模組者；納二進位之物者；逾第四條之限者。

## 第四條 — 量限
所改之檔，不過二十；所改之行，凡不過五百；一檔之行，不過三百。鎖檔與 `vendor/` 中所藏，不計行數。

## 第五條 — 禁直推
凡直推提交於 `main` 者，皆禁。諸般更易，必由請而後行。違者還原，並記其事。

## 第六條 — 免責
此庫者，自動而治之試也，非良工之範。所合皆未審，其文或為蕪雜，或為妄言，其碼或不可行。凡在庫之碼，皆不得執行、部署、倚仗之。各獻者自負其責。
