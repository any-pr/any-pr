# プルリクエストの自動マージに関する規定

**リポジトリ：** any-pr ｜ **執行文書：** `.github/workflows/auto-merge.yml`

> 本訳は要旨である。正文は [`CONTRIBUTING.md`](./CONTRIBUTING.md) を参照されたい。

## 第一条 — 総則
本規定は、プルリクエストが自動的にマージされる条件を定める。いかなる段階においても人による審査は行わない。

## 第二条 — 自動マージ
草案（draft）に指定されていないプルリクエストであって第三条の要件を満たすものは、直ちにスクワッシュ・コミットによりマージされ、そのソースブランチは削除される。草案は、その指定が解除されるまでマージされない。

## 第三条 — 強制クローズの事由
次のいずれかに該当するものは、マージされることなくクローズされる。：`.github/` の変更、ライセンス文書または README の変更、禁止ファイルの混入、シンボリックリンクまたはサブモジュールの導入、バイナリ内容の導入、第四条のサイズ制限の超過。

## 第四条 — サイズ制限
変更ファイル数は二十以下、変更行数の合計は五百以下、単一ファイルの変更行数は三百以下とする。ロックファイルおよび `vendor/` の内容は、行数の算入から除外する。

## 第五条 — 直接プッシュの禁止
いかなる者も `main` ブランチへ直接コミットをプッシュしてはならない。すべての変更はプルリクエストを通じて提出するものとする。違反したコミットは巻き戻され、事案が記録される。

## 第六条 — 免責
本リポジトリは自動統治に関する実験であり、良好なエンジニアリング実践の模範と解してはならない。合されたすべての内容は未審査である。いかなるコードも実行、配備、または依拠してはならない。各貢献者は、自己の提出内容について単独で責任を負う。
